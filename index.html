> Terminal d'Aide & Documentation

1. Navigation de base

  • Clique sur le bouton "Accéder" d'une carte pour ouvrir l'application ciblée dans un nouvel onglet.
  • Utilise le volet déroulant "Anciennes Versions" sous Genesis Omega pour retrouver les builds V1 et V2 historiques de ton projet.

2. Mode Camouflage Google (Secret)

  • Active-le depuis les paramètres pour masquer l'interface derrière une réplique exacte de Google.
  • Mots-clés directs : Entre directement genesis, ava, edu school ou justiss dans la barre pour court-circuiter le moteur et ouvrir tes applications secrètement.
  • Toute autre saisie lancera une vraie recherche Web transparente.
  • Pour sortir du mode discrétion, clique sur le bouton bleu "Connexion" en haut à droite.

3. Raccourcis Clavier

  • Échap : Ferme instantanément le bot d'accueil système ou quitte les modales.
  • Entrée : Valide et exécute tes recherches depuis le champ de saisie du mode Camouflage.

4. Personnalisation & Performance

  • Active le "Mode École" si tu es en classe pour basculer instantanément sur une police Inter épurée, sans lumières ni grilles.
  • Utilise le "Filtre CRT" pour simuler le rendu visuel d'un vieux moniteur des années 80.
  • Le "Mode Performance" supprime les transitions pour les machines plus lentes.
